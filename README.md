# Interview Preparation iOS

A sample iOS application for practicing modern app architecture, testing, and platform conventions across the Apple ecosystem.

## Getting Started

### Prerequisites
- Xcode 26.3 or later
- iOS 17 SDK or later (iOS 18 recommended)
- Swift 5.10 or later
- CocoaPods or Swift Package Manager (SPM) if the project uses dependencies

### Clone
```bash
git clone https://github.com/your-org/interview-preparation-ios.git
cd interview-preparation-ios
```
